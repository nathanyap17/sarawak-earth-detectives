# DATA_MODEL.md

> Contracts: `backend/app/schemas.py` (Pydantic v2). Stores: Cloud Firestore (cases, sessions) and files (vault series, answer keys). IDs: case ids are zero-padded strings ("001"); session ids are ULIDs generated by the backend. Timestamps: UTC ISO-8601, displayed in Asia/Kuching.

## Enumerations
| Enum | Values |
|---|---|
| CaseType | fire, haze, flood, dry, heat, land |
| CaseStatus | draft, open, closed |
| Tool | magnifier, season, ruler, scales, elnino, twin |
| Stamp | significant, not_significant, needs_more_years, record_too_short |
| Direction | rising, falling, flat |
| Overall | worsening, improving, no_change, not_enough_evidence |
| Ending | solved, solved_not_enough, sent_back |
| Badge | clean_signal, red_herring, honest_doubt, second_opinion, twin_trail, elnino_eye |

## 1 · `cases` (Firestore; also `cases/*.json` in the repo)
CasePack fields: see `schemas.CasePack`. Students can read only `status == "open"`. `relevant` and `red_herrings` are stripped before anything reaches the browser.

## 3 · Vault files (`data/vault/` locally, GCS in the cloud)
| Path | Content |
|---|---|
| `series/{region_id}/{card_id}.parquet` | Monthly values; yearly and normal are derived |
| `index.json` | Available (region, card) pairs with `data_as_of` |
| `answer_keys/{case_id}.json` | AnswerKey, **server-only** |

## Privacy and retention
| Concern | Handling |
|---|---|
| Student identity | Anonymous auth and a nickname only; no email, no real name |
| Minors | No free chat between students; the Partner stays on topic |
| Answer keys | Never in client-readable Firestore paths, never in API responses |
| Retention | Hackathon: sessions kept until judging ends, then deletable |
