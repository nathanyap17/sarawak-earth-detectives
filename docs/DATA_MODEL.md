# DATA_MODEL.md

> Contracts: `backend/app/schemas.py` (Pydantic v2). Stores: Cloud Firestore (cases, sessions) and files (vault series, answer keys). IDs: case ids are zero-padded strings ("001"); session ids are uuid4 hex generated by the backend. Timestamps: UTC ISO-8601, displayed in Asia/Kuching.

## Enumerations
| Enum | Values |
|---|---|
| CaseType | fire, haze, flood, dry, heat, land |
| CaseStatus | draft, open, closed |
| Tool | magnifier, season, ruler, scales, elnino, twin |
| Stamp | significant, not_significant, needs_more_years, record_too_short |
| Direction | rising, falling, flat |
| Overall | worsening, improving, no_change, not_enough_evidence |
| Ending | solved, solved_not_enough, sent_back |
| Badge | clean_signal, red_herring, honest_doubt, second_opinion, twin_trail, elnino_eye |

## 1 · `cases` (Firestore; also `cases/*.json` in the repo)
CasePack fields: see `schemas.CasePack`. Students can read only `status == "open"`. The browser and the Partner get `CasePublic`: no `red_herrings`, `main_cards` or `hints`. Card `worse_when` and `band` never leave `vault/cards.py`.

## 3 · Vault files (`data/vault/` locally, GCS in the cloud)
| Path | Content |
|---|---|
| `daily/{region_id}.parquet` | Region-averaged daily POWER record (land cells only) |
| `series/{region_id}/{card_id}.json` | Series contract: monthly, yearly, normal |
| `enso/roni_monthly.json` | RONI by centre month |
| `index.json` | Regions, land/sea cells, cards with year span and `data_as_of` |
| `answer_keys/{case_id}.json` | AnswerKey, **server-only** |

## Privacy and retention
| Concern | Handling |
|---|---|
| Student identity | Anonymous auth and a nickname only; no email, no real name |
| Minors | No free chat between students; the Partner stays on topic |
| Answer keys | Never in client-readable Firestore paths, never in API responses |
| Retention | Hackathon: sessions kept until judging ends, then deletable |

## Added 2026-11-15: case desk
- **`cases` (Firestore in cloud, `data/agency/cases/*.json` locally):** CasePacks drafted by the Scout and Case Builder. `status` is `draft` until a human approves (`open`) or rejects (`closed`). Hand-made cases stay in `cases/*.json` in the repository and win if an id clashes.
- **`answer_keys` (same store, server only):** the AnswerKey for each desk case, computed by code when the draft is built. Never returned by a student route; the editor's page shows only the overall verdict and the stamps.
- **`agent_activity`:** `{at, agent, by: ai|code|human, kind, text}`. Fixed wording and counts only: no student text, no nickname, no answer key, no text from an unapproved case. Read by `GET /agency/activity` (latest 40).
- **Routes:** `GET /agency/activity` (public) · `POST /admin/scout/run`, `GET /admin/cases`, `POST /admin/cases/{id}/approve|reject` (header `X-Admin-Token`).
- **`LogEvent.kind = "pins"`** with `pins: [[lon, lat], …]` (max 3) replaces the session's clue pins after a move or removal. The log stores only the count.
- **`AnalysisResult.enso_out`** (El Niño tool): the El Niño index for each year, for the scatter chart.
